Play from your own game files

The roBrowser relay is a browser extension. It lets the game pages load the game from the files on your computer instead of downloading them again from the server every time. Nothing is uploaded; your files stay in your browser.

About 10 minutes, once. Works in Firefox, Chrome, Edge, Brave and Opera, on a computer (not on a phone).

0Start the download

Download grf-offline-cyro.zip ({{SIZE}})

It takes a while. Do not wait for it: install the extension now (step 2), it does not need the zip. Once the download is done, extract it (right click → Extract All… on Windows, double click on macOS) and go on with step 3.

  1. Download roBrowser-relay-chrome.zip and extract it into a folder you will keep, for example Documents: you get a folder roBrowser-relay-chrome.

3Give it the game folder

  1. If you see the button Allow access to the game pages and cyro.live, click it, then Allow.
  2. Drag the game folder of the kit onto Drop your client folder here. Or click that box and choose the game folder.
  3. If the browser asks Upload files to this site?, answer yes: the "site" is the extension's own page, nothing leaves your computer.
  4. Wait while it copies the files into the browser (about a minute). It shows ✓ Ready.
  5. Go on with step 4. (The green Ready — open the game button opens the robrowser.suuuper.app page of step 4.)

To come back to this page later: click the extension's icon in the toolbar → Choose the client folder…

4Open the game

Log in with your cyro.live account as usual.

On cyro.live: cyro.live/rb2

cyro.live's own page. It needs the cyro.live patch, once, so that it reads your files:

  1. Install Tampermonkey for your browser.
  2. Chrome, Edge, Brave, Opera: chrome://extensions → Tampermonkey → Details → turn on Allow User Scripts (older versions: Developer mode, as in step 2).
  3. Open the cyro.live patch: Tampermonkey shows it → Install. It keeps itself up to date.
  4. Open cyro.live/rb2 (reload it if it was open) and log in. The popup shows ✓ cyro.live patch.
The link does not open? Install it from the kit
  1. Open extensions/tampermonkey/cyro-live-patch.user.js in a text editor (Notepad, TextEdit) and copy everything.
  2. Tampermonkey's icon → Create a new script… → select everything there, paste over it.
  3. File → Save (or Ctrl+S).

Or on robrowser.suuuper.app, no patch needed

5Check that it works

On the game page, the extension's icon in the toolbar shows GRF. Click it:

  • ✓ Ready — the extension holds your game folder.
  • ✓ The page took your folder — this page uses it.
  • ✓ No game file from the server — everything came from your computer.

6Free the disk space

Once you see ✓ Ready, the browser keeps its own copy of the game files. You can delete the zip and the game folder.

Installed from the kit on Chrome, Edge, Brave or Opera? Keep extensions/chrome: the browser runs the extension from it.

Something is wrong?

You seeDo this
"This page runs only with the roBrowser relay extension…"The extension is missing, turned off, or not allowed on the page. Do step 2 again, or open its popup and click Allow access… if it is there. Reload the page.
"The roBrowser relay is off or holds no client folder…"Open the popup: turn Relay on, or Choose the client folder… (step 3). Reload the page.
"The service worker does not control this page…"Reload normally (F5, Ctrl+R), not a forced reload. Private windows do not work.
◷ "The page has not taken your folder: reload it"Reload the page.
⚠︎ "N game files from the server"The game still plays; those files came from the server because your game folder lacks them. A newer kit has them.
✗ "cyro.live patch not installed"Only matters on cyro.live/rb2: the patch, in step 4.
The extension vanished or shows an error (Chrome, Edge…)extensions/chrome was moved or deleted. Put it back, or load it again from its new place (step 2), then give the game folder again (step 3).
No toolbar iconPin it: puzzle icon (Chrome) or ≡ → Add-ons (Firefox).

A new version

  • New extension, Firefox: install the new .xpi as in step 2. Your game folder stays.
  • New extension, Chrome, Edge, Brave, Opera (from the kit): replace the content of extensions/chrome with the new one, at the same place, then chrome://extensions → the reload arrow ↻ on roBrowser relay. Your game folder stays.
  • New game files: popup → Choose the client folder… → drop the new game folder.
