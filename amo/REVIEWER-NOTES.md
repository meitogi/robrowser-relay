Private beta. The extension hands a Ragnarok Online client folder the user owns (data.grf, several GB, plus loose files) to the roBrowser game pages on https://robrowser.suuuper.app/ (today https://robrowser.suuuper.app/upstream/cyro.live/, https://robrowser.suuuper.app/native-plugin-manager/cyro.live/ and https://robrowser.suuuper.app/cyro/cyro.live/; or their local copy on https://cyro.localhost/), so the page can load its assets without a file server. It does nothing on any other site. The code is not minified or bundled: the submitted files are the source, also at https://github.com/meitogi/robrowser-relay.

Test: install, open the welcome page (it opens on install), click "Allow access…", then drop any folder holding a .grf file (an empty file renamed test.grf is enough for the extension; the game itself needs a real client). The popup then shows "Ready". On https://robrowser.suuuper.app/upstream/cyro.live/ (open to everyone; the native-plugin-manager page asks for a beta access key) the <html> element gets data-ro-relay="ready" and the page shows "The extension is ready."

Permissions:
- webRequest + webRequestBlocking: https://cyro.live/api/ (the game server's API) sends no Access-Control-Allow-Origin header. While the relay is switched on, background.js adds it on the responses of https://cyro.live/api/* only, with the requesting origin as the value, and only when that origin is one of the two game origins (https://robrowser.suuuper.app, https://cyro.localhost:6988). Nothing is read, logged or redirected.
- unlimitedStorage: the client folder is stored in the extension's IndexedDB; the archive alone is about 4.4 GB.
- Host https://cyro.live/*: needed for the webRequest listener on https://cyro.live/api/*, and for content.js on https://cyro.live/rb2/: that page asks for the folder only when the user also installed the project's userscript (cyro-live-patch/ in the repository); without it, content.js only sets data-ro-relay there.
- Host https://robrowser.suuuper.app/*: the hosted game pages, one folder per client build and server (/<build>/<server>/); content.js runs there, and the background clears its toolbar badge on those tabs (tabs.query by URL).
- Host https://cyro.localhost/*: the same game page served by the player's own machine (*.localhost resolves to loopback only).

No remote code, no data collection (data_collection_permissions: none), no network request made by the extension itself.
